## 1. Claude/Anthropic → 테마 `anthropic`
- 팔레트: 캔버스 #FAF9F5 / 카드 #EFE9DE / 강조카드 #E8E0D2 / 다크 #181715 /
  잉크 #141413 / 본문 #3D3D3A / 뮤트 #6C6A64 / **코랄 #CC785C** / 헤어라인 #E6DFD8
- 타이포: 세리프 디스플레이 **400, 절대 볼드 금지** + 산스 본문. "더 굵게가 아니라 더 크게".
  → 한글: KoPubWorld바탕 헤드라인 + Pretendard
- 시그니처: 크림↔다크 서피스 교대(같은 서피스 연속 금지) · 풀블리드 코랄 콜아웃 카드 ·
  다크 코드윈도 카드 · featured = 다크 반전. 코랄은 페이지당 한 곳.
- 금지: 퓨어 화이트/쿨그레이 캔버스, 볼드 세리프, 블루 계열 악센트

## 2. Apple → 테마 `cupertino`
- 팔레트: 화이트 / 파치먼트 #F5F5F7 / 다크타일 #272729(#161617) / 잉크 #1D1D1F /
  뮤트 #86868B / **블루 #0066CC 단 하나** (다크 위에선 #2997FF) / 헤어라인 #E0E0E0
- 타이포: 웨이트 300/400/600 (**500 의도적 부재, 700 금지**), 전부 네거티브 트래킹.
  → 한글: Apple SD Gothic Neo (백업폴더 원본)
- 시그니처: 엣지투엣지 타일 교대(색 전환이 곧 구획선) · 중앙 정렬 스택(헤드라인→리드→
  블루 필 CTA 쌍) · 그림자 금지(제품 사진 아래 1개만 예외)
- 금지: 두 번째 악센트, 카드 그림자, 장식 그라데이션, ALL-CAPS

## 3. Stripe → 테마 `stripe`
- 팔레트: 화이트 / 소프트 #F6F9FC / 크림 인터루드 #F5E9D4 / **인디고 #533AFD** /
  네이비 #1C1E54 / 잉크 #0D253D(블랙 금지) / 뮤트 #64748D / 헤어라인 #E3E8EE
- 타이포: **디스플레이·본문 전부 weight 300** — 가벼움이 브랜드. 400 이상이면 "편집적 공기 붕괴".
  숫자는 전부 tnum 탭 정렬. → 한글: 에스코어드림 3 Light 디스플레이 + Pretendard
- 시그니처: 그라데이션 메시 히어로(크림→오렌지→라벤더→인디고→루비→마젠타; PPT는 블룸 PNG로) ·
  형제 카드 중 하나만 네이비 반전 · 인디고 필 CTA 밴드당 1개
- 금지: 300 초과 디스플레이, 그라데이션 스톱 외 새 악센트, 인디고 본문

## 4. Figma → 테마 `figma`
- 팔레트: 화이트 + **잉크 순수 블랙**(회색 텍스트 금지 — 위계는 웨이트로) /
  파스텔 블록: 라임 #DCEEB1 라일락 #C5B0F4 크림 #F4ECD6 핑크 #EFD4D4 민트 #C8E6CD
  코랄 #F3C9B6 네이비 #1F1D3D / 헤어라인 #E6E6E6
- 타이포: 모노(D2Coding) 아이브로우 = 항상 대문자·포지티브 트래킹. 디스플레이는 얇고 크게.
  → 한글: 더잠실 5 Bold 헤드라인 + Pretendard + D2Coding
- 시그니처: 뷰당 **파스텔 컬러블록 1개**(24px 라운드, 그 안에 에디토리얼 헤드라인) ·
  나머지는 전부 흑백 크롬 · 블랙 필 = primary · 네이비 블록 = 덱당 한 번의 다크 모먼트
- 금지: 그레이 본문, 블록 2개 연속, 블록에 그림자, 모노 본문

## 5. Vercel → 테마 `vercel`
- 팔레트: #FAFAFA 캔버스 / 화이트 카드+헤어라인 #EBEBEB / **잉크 #171717**(CTA도 다크밴드도
  같은 잉크) / 뮤트 #888888 / 링크블루 #0070F3 한 점 / 시안 #50E3C2 (코드 강조)
- 타이포: **웨이트 상한 600, 700 금지**, 강한 네거티브 트래킹, **문장형+마침표 헤드라인**
  ("지금 배포합니다."). 모노 대문자 아이브로우. → 한글: Freesentation 6 SemiBold + D2Coding
- 시그니처: 폴라리티 플립(#171717 풀블리드 다크 밴드 = 섹션 깊이) · 모노 아이브로우 ·
  블랙/화이트 필 쌍 · 메시 그라데이션은 히어로 스케일에서만
- 금지: ALL-CAPS 헤드라인, 700 웨이트, 작은 스케일 그라데이션, 모노 본문
