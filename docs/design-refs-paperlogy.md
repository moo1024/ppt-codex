**우리 gyoan 테마·SO WHAT 바·전달 우선 원칙의 직계 원전.** 사용자가 "이런 고급스러운 디자인"
의 기준으로 지목한 스튜디오의 실물 318장이므로, 프리미엄 의뢰에서는 이 문서가 1순위 문법이다.

## §1 최상위 시스템 (덱 OS) — 개별 장표보다 이게 핵심

1. **에피소드 사이클**: 다크 디바이더(질문 한 문장) → 증거 1~5장(스크린샷·목업, 텍스트 극절제)
   → 라이트 본문(정리, SO WHAT 앵커). "말할 것은 디바이더 한 문장, 보여줄 것은 증거,
   남길 것은 SO WHAT." 증거물 비율이 전체의 40~50% — 덱이 주장하고 캡처가 입증한다.
2. **Q→A 컷 분할**: 디바이더에 청중의 반문("그거 비싼 거 아닌가요?")을 질문형으로 던지고,
   다음 본문 헤드라인이 정면 응답("비쌉니다. 그런데 …아낍니다."). before/after 트윈 디바이더
   (같은 배경, 카피만 교체 p183↔187)도 같은 원리.
3. **챕터 악센트 통스왑**: 같은 골격에 악센트만 통째 교체(오렌지 강의 본편 → 블루 brandlogy
   납품물 → 레드/크림슨 리포트 → 네온그린 로고)로 "다른 클라이언트·다른 장"을 즉시 신호.
4. **존 잠금 스켈레톤**: 아이브로우 y0.05 · 헤드라인 y0.115~0.16 · 서브 y0.20 · 콘텐츠 존
   y0.27~0.80 · 클로저 밴드 y0.835~0.90 · Source 각주 y0.93 + 쪽번호. 마진 x0.035~0.045
   (우리 기본보다 타이트). 이 존은 못박고 **콘텐츠 존 내부만 페이지마다 골격 교체**.
5. **그레인 원칙**: 플랫 단색 배경이 318장 중 0장. 라이트=종이 그레인, 다크=그레인+미세 모눈
   이중 텍스처. 다크 광원은 채도 올린 그레인 블룸 — 플랫 그라데이션 금지.
6. 다크:라이트 ≈ 3:7. 다크가 나오면 "장이 바뀐다". 디바이더 헤드라인은 오히려 작게(~20pt) —
   광활한 어둠 속 작은 흰 문장, **여백 대비로 임팩트**를 낸다.

## §2 본문 표준 골격 (라이트)

- 아이브로우: "NN · 섹션명" 악센트색 자간+0.2em, x0.035 y0.05. 우상단 로고 글리프(✳) x0.95 고정.
- 헤드라인: 문장형+마침표, ExtraBold, 1줄. 구어체 존댓말 허용("이건 지금 외우지 마세요.").
  "A = B" / "A — B" 등식·대시 요약 구조 빈용.
- 콘텐츠 존 분할 레퍼토리(같은 골격 연속 금지): 65:35 인사이트 스플릿(기본형: 좌 증거 카드
  x0.035 w0.59 / 우 KEY POINT 카드 x0.645 w0.32) · 2단 등분(x0.04/0.51 w0.45) · 3카드
  (x0.035/0.355/0.67 w0.29) · 4~5열 체인 · 풀폭 표 · 메인+우측 레일(w0.56+0.34) · 2×2.
- **클로저 밴드 2강도**: 기본 = 베이지 틴트 바 + 악센트 자간 라벨(S O W H A T) + 먹색 문장 /
  강한 결론 = **니어블랙 라운드 바 + 악센트 라벨 + 흰 문장**. 덱 후반부로 갈수록 다크 클로저
  비율을 올려 무게를 격상. 라벨 어휘도 장마다 교체(SO WHAT/핵심/한 줄 규칙/회수/KEY TAKEAWAY).
- **전 본문 페이지에 Source 각주** ("Source: … · 추정치 반영" 수준까지) — 신뢰 장치.
- 카드: 순백, radius 크게(0.02~0.03), 그림자 거의 0. 카드 내부 위계는 헤어라인으로 분리.

## §4 타이포 규율

- **국영문 혼용 시그니처**: 산스 볼드 캡스 + 라틴 브랜드어만 세리프 이탤릭, 한 줄에 혼용
  ("EPISODE 01. *Claude.*", "brand*logy*."). 세리프는 악센트 폰트로만 — 본문 세리프 금지.
- 위계는 크기보다 **웨이트 대비**(ExtraBold↔Regular)와 양극단 크기(초대형 수치 vs 캡션,
  중간 건너뜀)로. 빅넘버는 숫자+기호(×↑↓)를 한 덩어리로, 단위는 1/4 크기.
- 부분 강조 규칙: 부분색은 페이지당 1~3어절, **판정·수치·대사에만**("62.4%", "틀림",
  "아니야, 해결해야 돼"). 부분웨이트는 캡션 핵심구만 볼드. 색과 웨이트 강조를 한 문장에
  겹치지 않는다. 헤드라인은 단색 유지(강조는 작은따옴표 '인용').
- 라벨은 전부 자간 확장 소형 캡스. 코드·명령어는 검정 필 안 모노 흰 글자.

## §5 색 규율

- 페이지당 실효 색: 배경중성 + 잉크 + **악센트 1계열**(틴트 3~5단 램프로만 확장). 강의 본편
  팔레트: 웜페이퍼 #EDEBE7 그레인 / 잉크 #1A1A1A / 테라코타 #D96C47 / 베이지 #EDE5D8 /
  다크서피스 #262322 — gyoan과 동일 계보.
- **서피스 3종이 곧 위계**: 흰 카드=사실 · 다크 카드=반전·핵심 · 오렌지 카드=결론·행동.
  본문 카드 N개 중 **정확히 1개만 반전**(주인공 노드 문법).
- **단일색 램프**: 서열·성장은 유채 2색이 아니라 한 색의 명도/채도 램프로(승격 계단 p66,
  히트 테이블 p188). **회색 강등**: 메시지 밖 항목은 회색으로 — 색 이분법이 곧 서술(p197).
- 스크린샷 속 시스템 색(iMessage 블루 등)은 "디제틱 UI 색" — 실물 재현에만 허용, 디자인
  요소로는 금지.

## §6 증거물 연출 (이 덱의 최대 자산)

- **캔버스 색 매칭**: 라이트 앱 캡처→라이트 지면, 다크 앱→순흑 지면. 베젤·가장자리가 배경에
  녹아 스크린만 떠 보인다. 스크린샷은 편집·보정 없이(diff 빨강초록, 마스킹 블랙바 그대로) —
  원본성이 신뢰다.
- **풀샷→크롭 줌 페어**: 같은 캡처를 풀샷 1장 → 결정적 문단만 확대(프레임을 슬라이드 밖으로
  잘라냄) 1장으로 잇는다. 카메라 워크의 슬라이드 이식.
- **폰 목업 프리미티브 조립**: card(다크 베젤 radius 0.09)+내부 card(흰 화면)+pill(노치)+
  말풍선 card들. 1대=한 장면/2대(x0.27·0.73)=전후 대비/3대(x0.155·0.40·0.645)=시퀀스.
  하단 블리드 허용.
- **채팅·문서 재현**: 캡처 대신 프리미티브로 위조(채팅 버블·MD 문서·견적서·세금계산서 직인
  까지) — 우리 "플레이스홀더 금지→직접 그리기" 규칙의 원전. 채팅 버블 컷은 순백 캔버스에
  버블 1개+타임스탬프, 여백 90%.
- 빈 양식→채워진 양식, 문서 상단부→하단부 등 **페이지 페어**로 전후를 증명.

## §9 우리 파이프라인 반영 판단

- **이미 있던 것의 원전 확인**: gyoan 팔레트·SO WHAT 바·문장형 헤드라인·전달 우선·플레이스
  홀더 금지·광원-텍스트 대각 분리 — 전부 이 자료가 뿌리. 검증된 규칙이므로 유지.
- **즉시 채택(전 덱 공통)**: 존 잠금 스켈레톤 + Source 각주 습관 · 클로저 밴드 2강도(다크
  격상판) · 부분색 1~3어절 규칙 · 산스캡스+세리프 이탤릭 아이브로우 · 서피스 반전 1개
  원칙 · 단일색 램프/회색 강등 · Q→A 컷 분할과 에피소드 사이클.
