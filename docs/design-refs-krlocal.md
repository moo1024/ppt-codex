## 1. 그룹별 핵심 문법

### A. 빅테크 소개서 (카카오엔터·네이버페이·토스)
- 6층 페이지 골격: ①좌상 브레드크럼(`01 | 섹션명` 브랜드색) ②브랜드 헤어라인(전폭 1.5~2px)
  ③헤드라인(센터+반전 키워드박스, 또는 좌 초볼드+우 그레이 리드 비대칭) ④리드 1~3줄
  ⑤콘텐츠(카드/표/도식) ⑥풋터(로고 좌+쪽번호 우)
- 컬러 규율: 브랜드 1색 + 잉크 + 그레이 + 파스텔 틴트. 보조색은 3분류 대비에만
- 표지 2계보: 다크(근검정+저대비 기하 패턴+브랜드색 1행/화이트 1행) / 라이트(페일 그라데이션+센터)
- 디바이더 = 번호+타이틀+브랜드 컬러필드, 정보량 최소로 리듬 형성
- 팔레트: 네이버그린 #03C75A(+네온 #00DE5A/다크 #0E1210), 토스블루 #3182F6/#1B64DA
  (+페일 #EEF3FC, 잉크 #191F28), 카카오 옐로 #FFE300+코발트 #0533DD+페이퍼 #EDEEF0
- 클로징 문법: 풀블리드 브랜드색 + 알파 6~10% 초대형 로고 워터마크 + 센터 선언문

### B. 산학 브로슈어 (LINC·조선대·울산대 등)
- 표지: 기하 브랜드 모티프 1개(아이소 큐브/헥사곤/캡슐) + 기관명 2단 + 하단 로고 스트립
- 디바이더: 풀블리드 섹션색 + 초대형 챕터 숫자(페이지 높이 28~32%) + 흰 헤어라인
- 본문: 챕터 헤더 유닛(대형 번호+세로 헤어라인+2줄 타이틀) + **좌측 라벨 레일(폭 15~20%)**
- **틴트 3단계 시스템**: 솔리드 100%(헤더) / 40%(보조 칩) / 8%(박스 배경) — 이 규칙 하나로
  관공서 브로슈어 톤 재현. 예: 그린 #1FA05A / #A5DBBC / #E6F4EA
- 섹션 컬러 로테이션(PART별 틸→블루→그린→퍼플) 허용
- 팔레트 예: 인디고 #2B3990+스카이 #4A90D9+오렌지 #F08A24 / 레드 #C8102E+네이비 #1B3A6B

### C. 심사장표 (RISE 경북대 — 발표형 관공서 장표의 원형)
- **3단 헤더 시스템**: 최상단 목차 탭 내비밴드(현재 장만 강조색, h 4.5%) → 장 제목
  (Ⅳ. 로마숫자+ExtraBold 28pt) → 절 필(강조색 솔리드+흰 글자). 매 페이지 동일 좌표
- **코드칩 넘버링**: 과제에 `1-1` `E-03` 코드 부여, 짙은 칩으로 어디서든 앵커
- 색 운영: 구조색(틸 #0E6E5F 7) : 성과색(크림슨 #C8102E 2) : 성장색(오렌지 #E8833A 1)
- 밀도 관리 4원칙: 흰 카드+헤어라인 구획 후 내부만 9pt 압축 / 숫자 크게·설명 작게(4:1) /
  2색+무채색, 강조 1색 페이지당 3회 이하 / 반복 구조는 스타일 완전 복제
- 하단 선언 바(풀폭 짙은 바+한 문장) = SO WHAT의 관공서 버전
- 우측 스포트박스: 콘텐츠 좌 62% + 우 34% 강조 테두리(2.5pt) 카드에 성과목표 — "채점 포인트" 신호

### D. 정부 보고서형 (HWP 계열 사업계획서 — 흑백/저채도)
- 그레이스케일 5단만으로 성립: #F5F5F5/#E7E7E7/#D8D8D8/#9A9A9A/#3A3A3A + accent 1색
- 기호 위계가 스타일시트: 장(Ⅰ) > 절(회색 밴드) > 가./나. bold > ○/• > -
- 워크호스 = **좌측 레일 스펙 테이블**(레이블 컬럼 12~16% 회색필 + 콘텐츠 88%)
  + **연도 레일 로드맵**(네이비 연도 셀+불릿) + **미니 간트**(4등분 헤더+스팬 바)
- 하단 고정 밴드 2종: 재원 4셀(대학혁신/교비/타사업/총액) + 모니터링 4셀
- 과제 헤더 유닛: 다크 라운드 번호 칩 + 제목 + 우측 '핵심' 태그 칩 + 헤어라인

  하이라이트 + 카드 소프트 섀도우(저 opacity) + 1px 블루그레이 정렬선 적극 사용

- **리프트 카드**: 동급 카드 N개 중 1개만 위로 띄우고(y-40px) 액센트 솔리드 — "지금 이 얘기"

  + 킬러 행 오렌지 아웃라인 — 표를 주장으로 바꾸는 기법
- **3분할 헤더 밴드**: 좌 메타 / 중 챕터 / 우 팀명 — 공모전 표준 (IDLE·STATUS)
- **하단 풀폭 결론 필**: 모든 차트 페이지가 "증거 → 하단 한 문장 판단"으로 끝남
  (우리 sowhat과 동일 사상 — 대회 수상작 2종이 공통 채택)
- **스테이지 필 내비**: 상단 중앙 백 캡슐 `(Problem) 니즈확인` — 목차 없는 위치 감각
- **듀오톤 사진 딤**: 풀블리드 사진 + 브랜드색 60~75% 오버레이 + 백 타이포
- **거대 숫자 오버레이**: 사진 위 130pt+ 연도/수치 (높이의 30~40%), 부가 텍스트는 1/4 이하
- **필름스트립 캐러셀**: 하단 썸네일 띠 + 중앙 1장 확대 + 도트 페이지네이션
