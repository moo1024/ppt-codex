## 페이지 골격
- **표지**: 좌측 세로 크림슨 밴드(w0.285) + 흰 교표·교명 / 우측: 레드 서브타이틀 →
  "결과보고서" 초대형(44pt) → 레드 언더라인 → 하단 라벨칩(주최/주관/수행/일자) 행 +
  헤어라인 / 우하단 연红 교표 워터마크.
- **내지 공통**: 상단 좌 "「행사명」 결과보고서"(8pt gray) + 우 기관명 bold. 하단 좌
  레드 틱바 + "NN 장제목" 푸터.
- **챕터 헤더**: 좌마진 "01"(40pt red ExtraBold) + 그 아래 CHAPTER 캡션 + 레드 화살표 →,
  우측 장제목(27pt red) + 리드 문단 2~3줄. ※ CHAPTER 캡션은 넘버 아래 y+0.074 이상
  (겹침 주의 — gyeolbo-civic에서 실측 보정).
- **좌마진 레이블**: 본문 좌측 여백(x0.045)에 레드 볼드 소제목 + 위에 긴 레드 화살표.
- **레드 필 소제목 바**: 틴트 필(outline red, radius 0.5) + 좌측 교표 칩 + 레드 볼드
  제목 — 절 단위 반복. (red_pill 헬퍼)
- **표**: 헤더 행 = 레드 세로 그라데(card grad [FC3E31→D80C18]) + 백색 볼드, 본문 행 =
  hairline 구분 + 구분 컬럼만 틴트 카드.
- **라벨:값 정보 리스트**: 레드 라벨(볼드) + 잉크 값, 행간 0.038~0.042.
- **체브런 타임라인**: 농도램프(틴트→크림슨) 4단, 마지막 두 단은 백색 텍스트.
- **증빙 사진**: 4:3 통일 크롭, 2×2 그리드(w0.30), 사진 아래 "▲ 캡션" 아웃라인 필.
  실사진 없을 때도 회색 IMAGE 박스 금지(규칙 7) — 교표 워터마크 카드로 대체.
- **참여자 후기**: 틴트 카드 2×2에 따옴표 인용문 (채팅 캡처 원문에서 발췌).
- **마무리**: 레드 그라데 선언 밴드("…정상적으로 완료하였음을 보고합니다") + 우하단
  일자·기관 서명행.

## 에셋
교표는 템플릿 pptx의 `ppt/media/image9.png`(회색 원형 교표)를 리컬러:
크림슨(#D80C18, α=마스크) = 칩용 / 동일 색 α×0.10 = 워터마크 / 백색 = 표지 밴드용.
루미넌스 마스크 = (255-L)/(255-L_min). 산출물: projects/<slug>/assets/brand/emblem_*.png
(projects는 gitignore — 새 프로젝트마다 gyeolbo-civic에서 복사하거나 재생성).

## A4 세로 렌더
layout_spec에 `"page_size": "a4p"` (덱 단위, 첫 페이지 스펙 기준). 좌표는 여전히 0~1
비율. **정사각 보정**: y높이 = x폭 × 7.5/10.833 (SQ≈0.692). 4:3 사진 h = w×0.519.
사진은 반드시 원본 종횡비에 맞춰 w/h 지정 (이미지 아이템은 강제 스트레치).
본문 폰트는 9.5~10.5pt 고밀도 — 문서형이므로 발표용 TYPE SCALE보다 작게 쓴다.
