## §1 6가지 관통 원칙 (원문 — 슬라이드에도 그대로 유효)

1. **신뢰가 걸린 곳엔 화려함을 버린다** — 금융·법률·의료·정부는 미니멀+고대비+절제된 블루.
   공통 금지 = 장난기 · **AI 보라/핑크 그라디언트**.
2. **데이터는 다크, 콘텐츠는 라이트** — 숫자를 오래 응시하는 화면(차트·모니터링)은 다크 기본,
   읽고 사는 화면(문서·교육·커머스)은 라이트 기본. "다크를 기본으로"가 금지인 업종도 많다.
3. **애니메이션 시간엔 이유가 있다** — 생산성 150ms / 일반 호버 200~250ms / 럭셔리 400~600ms.
   (정적 슬라이드엔 직접 전이 안 되나, "럭셔리=느림"의 정서는 여백·전개 속도로 번역).
4. **감정을 팔면 채도를 올려라** — 데이팅·소셜·푸드·게임은 비비드+웜. B2B·보험은 저채도. 채도=심박수.
5. **접근성은 스타일보다 우선한다** — 헬스·정부·시니어는 WCAG AAA·16px+·명확한 포커스가 필수.
6. **금지 패턴이 절반이다** — 무엇을 하지 말지가 무엇을 할지만큼 중요. 각 룰의 forbidden이 실패 요약.

## §2 상태색·잉크 표준 (161종 전량이 공유 — 즉시 채택)

- **잉크 = `#0F172A`(슬레이트), 순흑 아님.** 텍스트·다크 배경 기본값. 다크 커버/디바이더도 순흑보다
  이 톤이 부드럽고 프리미엄. (우리 다크 variant 기본 잉크로 참고 — 테마별 dark_bg가 순흑에 가까우면 완화 검토)
- **상태색 페어 = 그린 `#059669`↑(성공·상승·안전) / 레드 `#DC2626`↓(경고·하락·손실).** 앰버 `#F59E0B`=주의.
  차트 증감·상태 칩·비교표에 이 페어를 테마 불문 채택. **레드는 부정·긴급에만, 본문·장식 남용 금지.**
- **접근성**: 색상 단독 상태표시 금지 — 아이콘/텍스트 병기 (색약·흑백 인쇄 대응). 제안서 신뢰 디테일.

## §5 모던 스타일 용어집 → 렌더러 근사 판정 (glossary 20종)

- **완전 이식**(기본 렌더): 플랫 · 미니멀 · 비비드 블록(풀채도 fill card) · 벤토 그리드(크기 다른 card
  짜맞춤 — "3카드 반복 금지"의 대안 골격) · 스위스 모더니즘(edito 헤어라인 그리드) · 브루탈리즘(thick
  hairline+하드엣지, vividbrief/yellowblack).
- **인상만 근사**(프리미티브 조합): 글래스모피즘(흐린 배경 이미지+반투명 밝은 card+가는 흰 outline —
  진짜 blur 불가) · 뉴모피즘/소프트UI(동색 card+shadow, 단 저대비라 슬라이드 가독성 위험) · 클레이모피즘
  (큰 radius+컬러 shadow+상단 밝은 grad, malang/springnote 감성) · 오로라(glow 다중+grad 배경) ·
  HUD/홀로그래픽(가는 hairline 코너 브래킷+glow+다크, 데이터 대시 커버) · 사이버펑크(다크+네온 spec color).
- **정적 슬라이드 폐기**: 리퀴드 글래스(굴절 불가 → 프리미엄은 goldnavy/mukgold) · 모션 드리븐 ·
  마이크로 인터랙션. **파스텔·저대비는 빔/인쇄에서 안 보임 — 웰니스 톤도 텍스트 대비는 반드시 확보.**
