## 0. 판형·그리드

- 캔버스 **7.5 × 10.83 in** (6858000 × 9906000 EMU, 비율 1:1.444). 세로 문서. A4(1:1.414)에 근접하나 살짝 더 김.
- 좌우 여백 ≈ 0.55in. 상단 헤더존 / 좌측 라벨 레일(폭 ≈ 1.4in) / 우측 콘텐츠존 / 하단 푸터존.
- **좌측 라벨 레일 그리드**가 이 시스템의 척추: 한 페이지에 2~4개 섹션을 세로로 쌓고, 각 섹션 = [좌:파란 볼드 라벨] + [우:내용 블록].

## 4. 재사용 컴포넌트 문법 (조립 카탈로그)

- **바이링구얼 섹션 헤더**: 상단 헤어라인 → 국문 ExtraBold 네이비 / 영문 Medium 그레이 2줄 → 좌하단 네이비 짧은 언더바.
- **좌측 라벨 레일**: 좌 폭≈1.4in에 파란 볼드 라벨, 우측에 리드문(볼드 국문)+본문. 한 페이지 2~4단 세로 스택. **문서형 밀도의 핵심** — 죽은 세로 여백 금지.
- **스탯 카드 행**: 틴트 배경 라운드 카드, 40pt 네이비 수치 + 하단 라벨. 3~4개 행.
- **아이콘 쿼드/트리오**: 플랫 SVG 아이콘 + 볼드 타이틀 + 캡션, 사이 **세로 헤어라인** 분할.
- **넘버서클 체인**: 원+넘버칩 → 라인 커넥터 → 단계명·캡션은 전부 원 아래(=CLAUDE.md 규칙8 준수). 체브론 안 글자 금지.
- **컬러 스와임레인**: 컬럼 헤더 = 주체별 색(네이비/골드/레드), 아래 실선/점선 화살표 흐름. 행 = 단계.
- **비교 표**: 네이비 헤더행(흰 글자), 좌 라벨열 틴트, **강조 열은 네이비 테두리 + 파란 글자**.
- **다크 네이비 밴드**: 라운드 네이비 바 + 방패/로고 아이콘 + 흰색 한 줄 결론문 (섹션 클로저).
- **도넛/파이**: 20/80 등 관계 수치는 도넛, 큰 쪽에 골드.
- **푸터**: 좌 = 페이지번호(볼드 네이비)+덱 타이틀. 본문 하단 = 라운드 pill에 전화·이메일 아이콘+연락처.
- **스왑 슬롯**(제안서마다 바뀌는 것): 커버 로고/브랜드색·태그라인, 연락처(전화·이메일·담당자), 운영사 스탯·포트폴리오, 유스케이스 4종, 일정·비용 수치, 산출물 목록.

## 5. 자산

- 아이콘 = **플랫 벡터 SVG 세트**(덱당 41~43개) + PNG 폴백. 톤: 라인+틴트면, 네이비/블루 단색계. 일관 세트 유지가 관건(섞으면 촌스러움).
- 포트폴리오 썸네일(운영사 페이지) = 실제 행사 포스터 PNG 2×5 그리드.
- QR = 운영사 링크.
